# 推理 · THE ART OF REASONING

一部用 HTML 写成的约 6 分钟史诗短片：从宇宙洪荒、拉斯科洞穴的足迹，到亚里士多德、宋慈、福尔摩斯、图灵、DNA、AlphaGo，再到今天的 AI 推理模型。

## 观看

- **Windows**：双击 `播放电影.bat`，会用 Chrome 或 Edge 全屏自动播放（按 F11 或 Alt+F4 退出）
- **其他系统**：用浏览器打开 `index.html`，点击「开始放映」

快捷键：空格 暂停 · ← → 切换章节 · F 全屏 · M 静音

## 技术

- 纯 HTML / CSS / JavaScript，单文件，无构建步骤
- 配乐与音效全部由 Web Audio API 实时合成（弦乐、合唱、铜管、太鼓）
- 画面特效：Canvas 粒子、Web Animations API 时间轴
- 字体通过 Google Fonts 在线加载
